## Running `tracking_output.py`

The script takes **four inputs**:

1. **Video folder input**  
   Folder in which all the videos are stored.

2. **Video string**  
   A string such as `"video_center"`.  
   The script searches for `.mp4` files in the video input folder that contain this string.

3. **Video output folder**  
   Stores the output videos.

4. **CSV output folder**  
   Stores the output CSV files with the tracking values.
